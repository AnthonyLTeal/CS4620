## Build Instructions
To build, first install dotnet 8 and dotnet 6, then run either `dotnet run` from the directory within the project, or run `dotnet build CS4620IS`

To install dotnet 8 and 6 on Windows, visit https://dotnet.microsoft.com/en-us/download/dotnet/6.0, https://dotnet.microsoft.com/en-us/download/dotnet/8.0

Dotnet 6 is not supported on Ubuntu right now so it might not work, but you can still install dotnet 8: https://learn.microsoft.com/en-us/dotnet/core/install/linux-ubuntu-install?tabs=dotnet8&pivots=os-linux-ubuntu-2604 (there was a dependency removed and it's possible dotnet 6 is no longer required, but I'm not 100% sure)
